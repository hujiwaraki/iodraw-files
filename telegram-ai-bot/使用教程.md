# Telegram AI 陪聊机器人：零代码部署教程

全程大约 20 分钟，只需要复制、粘贴和双击。

## 第 0 步：下载这个文件夹
打开仓库页面，点击绿色的 **Code** 按钮，选择 **Download ZIP**，解压后找到 `telegram-ai-bot` 文件夹。

## 第 1 步：安装 Python
1. 打开 https://www.python.org/downloads/ ，下载并安装。
2. **Windows 用户注意**：安装界面最下方的 **Add Python to PATH** 一定要勾选。

## 第 2 步：创建 Telegram 机器人，拿到令牌
1. 在 Telegram 搜索 **@BotFather**（认准带蓝色认证勾的那个），点击 Start。
2. 发送 `/newbot`。
3. 按提示输入机器人的显示名字，例如 `小暖`。
4. 再输入用户名，必须以 `bot` 结尾，例如 `xiaonuan_chat_bot`。
5. BotFather 会回复一串类似 `7123456789:AAH...` 的文字，这就是**令牌**，复制下来。

## 第 3 步：拿到 OpenAI API Key
1. 打开 https://platform.openai.com/ 并登录。
2. 在 **Settings → Billing** 充值（最低 5 美元，陪聊一般能用很久）。
3. 打开 https://platform.openai.com/api-keys ，点击 **Create new secret key**，复制以 `sk-` 开头的密钥。密钥只显示一次，请保存好。

## 第 4 步：填写配置
用记事本（Mac 上用“文本编辑”）打开 `config.txt`：
- 把 `TELEGRAM_TOKEN=填这里` 改成 `TELEGRAM_TOKEN=你的令牌`
- 把 `OPENAI_API_KEY=填这里` 改成 `OPENAI_API_KEY=sk-你的密钥`
- **国内用户**：在 `PROXY=` 后面填上你的代理地址。Clash 默认是 `http://127.0.0.1:7890`，具体端口可以在代理软件的设置里查看。

保存文件。

## 第 5 步：启动
- **Windows**：双击 `启动-Windows.bat`
- **Mac**：右键点击 `启动-Mac.command`，选择“打开”。第一次运行会弹出安全提示，再点一次“打开”。

窗口里出现 `✅ 机器人 @xxx 已上线！` 就说明启动成功了。

## 第 6 步：开始聊天并设为私用（重要）
1. 在 Telegram 搜索你的机器人用户名，点击 Start，随便聊几句。
2. 发送 `/myid`，记下它回复的数字。
3. 关闭启动窗口，在 `config.txt` 里填写 `ALLOWED_USERS=刚才的数字`，然后重新启动。

**这一步一定要做**，否则陌生人也能用你的机器人，花的是你的钱。

## 常用操作
| 想要 | 怎么做 |
|---|---|
| 改性格、名字 | 修改 `persona.txt`，然后重新启动 |
| 清空它的记忆 | 在聊天里发送 `/reset` |
| 关掉机器人 | 关闭启动窗口 |

## 常见问题
- **启动时提示“连不上 Telegram”**：国内需要设置 `PROXY`，并确认代理软件已经打开。
- **机器人回复“我刚刚走神了”**：查看启动窗口里的报错。`401` 表示 API Key 填错了，`429` 表示余额不足或请求太频繁，`404` 或提示 model 错误表示模型名不可用，可以把 `OPENAI_MODEL` 改成 `gpt-4o-mini` 试试。
- **电脑关机或睡眠后机器人就不回复了**：这是正常的，机器人运行在你的电脑上。想让它 24 小时在线，需要部署到云服务器。
