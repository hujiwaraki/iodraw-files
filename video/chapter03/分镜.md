# 此心安处 · 第三章 从游客到旅人 — 分镜第十稿

- 画幅：9:16 竖屏，约 218 秒
- 第十稿：重新梳理逻辑。订错机票、出租车上一路哭的那一夜放回开头（就是“第一次上路”那一次）；“重锤”放进“一次次出发”里，和变得自信合成一节；新手村夹在中间，接“就这样跌跌撞撞”；“变得自信”和“以前 / 后来”之间加两句过渡：旅行的样子变了，J 人变成了 P 人
- 画面语言：**镜头一直跟着她走**。上一个场景她走出画面，下一个场景她从另一边走进来，不再翻页、不用道具转场
- 成长靠细节，不靠大字对比：
  - 帽檐：压得很低 → 往上一推 → 后来干脆背在身后
  - 步子：小心翼翼拖着箱子 → 越走越快、越走越大步
  - 颜色：灰 → 一点点回暖，整章渐变，不分块突变
- “以前 / 后来”：**同一个地方、同一个机位拍两遍**，让观众自己看出变化
- 与第二章不雷同：不用铁盒、书桌、车票地图、圆桌、季节轮换、视线线条
- 人物：黄外套、草帽；背包从第 12 句“十分钟收好一个背包”开始；戴帽子时 A 侧分短发
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 配乐：一条旋律慢慢长出来
- 整章同一个主旋律、速度基本不变，只换乐器和编配
- 并不浪漫：零散的单音吉他，中间留很多空白；夜路只有脚步声和低低的大提琴
- 游客：加一个机械的节拍，像在赶时间；快门声嵌进节拍里
- 重锤（第十稿分到开头和“一次次出发”两处）：夜雨、出租车低低的引擎声和大提琴；乌云下几乎只剩一个长音，路灯熄灭时轻轻的“嗒”；天亮时几声鸟叫；一路走时像重锤一样一下一下的低鼓，绊倒、水坑、跳过沟都有声音；乌云散开时一串八音盒，晴了以后吉他轻快起来
- 变自信：同一段旋律转成大调，第一次完整地弹出来
- 以前 / 后来：不再来回切换。“以前”时音乐只是收轻，“后来”一层一层往上加：低音 → 分解和弦 → 轻打击乐 → 全部到位，四组听下来是一路渐强
- 当地生活：手鼓、拨弦，最热闹
- 结尾：热闹慢慢退去，只剩一把吉他，回到片头的旋律
- 段落之间用延长音和渐变过渡，不硬切

## 整章逻辑
第一次一个人上路，订错机票，在出租车上哭了一路，才明白一个人旅行一点也不浪漫 → 旅途有危险，而那时候一点小麻烦都像天塌了，陷在情绪里久久缓不过来 → 天亮了，还是要一个人吃饭、看风景，最怕别人的眼光 → 那时只是打卡的游客 → 后来一次又一次地出发，才慢慢明白成长是生活的重锤一下一下凿出来的，终于跨过一道坎；可等到下一个困难来临，又回到了新手村 → 就这样跌跌撞撞，走过更大的世界，慢慢变得自信，也学会了接受倒霉和如约而至的困难 → 一个人吃饭不再在意眼光 → 连旅行的样子也变了，从凡事都要计划的 J 人变成随遇而安的 P 人 → 以前 / 后来 → 走进当地人的生活 → 从游客变成了旅人
