# 此心安处 · 第四章 不敢抵达的地方 — 分镜第二稿

- 画幅：9:16 竖屏，约 125 秒
- 画面语言：前半章“去哪都不对”——换了很多房间、很多海岸，心还是没落地，锚抛不下去；后半章进入那些不敢一个人抵达的蜜月圣地，一切都是成双的
- 与前三章不雷同：不用铁盒、车票、手账、走路横移、明信片架、圆桌、情侣自拍
- “此心安处是吾乡”留到第八章再说，这一章不提
- 不出现具体地名：用“蜜月圣地”“蓝白色的海岛”“海上的小木屋”
- 色调：灰蓝的夜 → 月光的海 → 蜜月圣地：过分饱和的蓝和金（美得有点压人）→ 结尾一点点暖
- 音乐：钢琴 + 弦乐铺底，偏慢，带一点惆怅；主旋律放慢一半
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 片头（6 秒）
墨绿色的书翻开到“第四章 · 不敢抵达的地方”，配图：一只小小的船锚。

## 一、去哪都不对（约 45 秒）
| # | 字幕 | 画面 |
|---|---|---|
| 1 | 一个人漂泊了很久， / 渐渐像是选择了流浪。 / 可去到哪里，↵好像都不太对。 | 同一个机位，她躺在不同旅馆的床上，望着天花板：窗外从雪山换成海边、换成霓虹的城市、换成沙漠，墙纸和床单也一次次换掉，只有她的姿势一直没变。最后一次换的时候，床变成了一只小船 |
| 2 | 可好像从来没有↵一个具体的锚点。 | 小船漂在月光的海上。她把一只船锚抛下去，绳子一圈圈往下放，镜头跟着锚沉下去：绳子放到了头，锚还悬在水里，碰不到底 |
| 3 | 没有一座城市， / 没有一种生活， / 也没有一个人，↵让人强烈地想说： | 小船漂过三座小岛，每一座她都举起锚，又放下：<br>① 灯火通明的城市<br>② 冒着炊烟、种着菜的小木屋<br>③ 码头上一个人的背影，向她挥挥手，又被雾慢慢遮住 |
| 4 | 就是这里了。 / 想留下来。 | 小船靠上沙滩。她用树枝在沙子上写“就是这里了”，退后一步看看。一个浪打过来，字被抹平了 |
| 5 | 有时候甚至分不清， / 是还没找到↵能让人安心停下的地方， / 还是自己本来就是↵一个很难被锚住的人。 | ①水下剖面：锚悬在深蓝的海水里，下面看不到底<br>②她把锚拉上来捧在手里，原来是纸折的<br>③一阵风吹过，纸锚从她手里飘起来，像风筝一样越飞越高，飞进晨光里 |

## 二、不敢抵达的地方（约 52 秒）
| # | 字幕 | 画面 |
|---|---|---|
| 6 | 可即使习惯了一个人走，↵也不是哪里都敢去。 | 天亮了，纸锚飘过一条街，落在旅行社的橱窗前。橱窗贴满海报：雪山、沙漠、古城、雨林。她背着包一张张看过去，每张都轻松地点点头，走到最后一张前停住了 |
| 7 | 有些地方，↵到现在仍不敢一个人抵达。 | 最后一张海报上写着“蜜月之选 · 双人成行”，画着蓝白色的海岛。她伸手想碰，手停在玻璃前，又收了回来 |
| 8 | 比如那些被叫作↵蜜月圣地的地方： / 蓝白色的海岛，↵海上的小木屋。 | 镜头穿过玻璃，进入海报：<br>①白房子、蓝圆顶，一对新人在台阶上拍婚纱照，白纱被风吹起<br>②碧绿的浅海上，木栈道连着一间间水上小木屋，门口挂着“蜜月套房”的牌子，床上用花瓣摆成一颗心 |
| 9 | 总觉得那些地方↵太适合两个人了。 | 那里的一切都是成双的：露台上两把躺椅、桌上两只香槟杯、栈道尽头一架双人秋千、水里两只一起游过的海龟 |
| 10 | 海太蓝， / 落日太盛大， / 夜晚又太安静。 | 三个镜头：<br>①蓝得发亮的浅海，一圈圈光斑<br>②巨大的落日几乎铺满画面，把白房子染成金色<br>③夜里，海面一点声音也没有，只有满天星星，和水上小木屋里的一盏灯 |
| 11 | 一个人站在那里， / 那些本该叫人幸福的风景， / 大概会让成千上万种孤独↵一起压下来。 | 她一个人站在露台上，身边是两把躺椅。落日越来越大，天空越来越高，她显得越来越小。第三屏：天上落下成千上万个灰色的小光点，像下雪一样，一层层压下来 |
| 12 | 并没有强大到↵可以独自承受所有风景。 | 她往后退了一步。镜头一下子退出海报，回到街上的橱窗前：她站在玻璃外，海报上的落日安安静静 |

## 整章逻辑
漂泊了很久，像选择了流浪，去哪都不太对 → 从来没有锚点，分不清是没找到地方，还是自己本来就难被锚住 → 习惯了一个人走，却仍有不敢一个人抵达的地方 → 那些蜜月圣地太适合两个人，风景太盛大，一个人承受不住 → 想把它们留给某一个人，也留给一群人：爱人、家人、老朋友（下一章：一个人出发以后，也并不总是一个人）
