# 此心安处 · 第四章 不敢抵达的地方 — 分镜第一稿

- 画幅：9:16 竖屏，约 130 秒
- 画面语言：**一条没有锚地的小船**。前半章用“抛不下的锚”讲“没有锚点”；后半章进入那些不敢抵达的风景，用“成双成对的东西”讲“太适合两个人”
- 与前三章不雷同：不用铁盒、车票、手账、走路横移、明信片架、圆桌、情侣自拍
- 呼应：第一章墙上那枚船锚图钉（这里它变成真正的锚）；第三章放回去的蓝白海岛明信片（这里是她终于“看见”那个地方）
- 不出现具体地名：圣托里尼、马尔代夫只用画面表现（蓝白的海岛、水上的木屋），字幕里也不写地名
- 色调：月夜的深蓝 → 海面的灰蓝 → 不敢抵达的地方：过分饱和的蓝和金（美得有点压人）→ 收回到暖暗的房间
- 音乐：钢琴 + 弦乐铺底，偏慢，带一点惆怅；主旋律放慢一半
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 片头（6 秒）
墨绿色的书翻开到“第四章 · 不敢抵达的地方”，配图：一只小小的船锚。

## 一、没有锚点（约 55 秒）
| # | 字幕 | 画面 |
|---|---|---|
| 1 | 也常常想起苏轼的那句： / 此心安处是吾乡。 | 夜里，她坐在旅馆的屋顶上，抱着膝盖看月亮。第二屏时，“此心安处是吾乡”七个字像毛笔字一样，一笔一笔写在月亮旁边的夜空里 |
| 2 | 可好像从来没有↵一个具体的锚点。 | 月光铺成一片海。她坐在一只小船上，把一只船锚抛下去，绳子一圈一圈往下放，镜头跟着锚沉下去：海水越来越深，绳子放到了头，锚还悬在半空，碰不到底 |
| 3 | 没有一座城市， / 没有一种生活， / 也没有一个人，↵让人强烈地想说： | 小船漂过三座小岛，每一座她都举起锚，又放下：<br>① 一座亮着灯的城市，高楼的窗一格格亮着<br>② 一间冒着炊烟的小木屋，门口晾着衣服、种着菜<br>③ 码头上站着一个人的背影，向她挥了挥手，又被雾慢慢遮住 |
| 4 | 就是这里了。 / 想留下来。 | 小船靠上一片沙滩。她跳下船，用树枝在沙子上写“就是这里了”，退后一步看了看。一个浪打过来，字被抹平了 |
| 5 | 有时候甚至分不清， / 是还没找到↵能让人安心停下的地方， / 还是自己本来就是↵一个很难被锚住的人。 | ①水下的剖面：锚悬在深蓝的海水里，下面看不到底<br>②她把锚拉上来，捧在手里看，锚是纸折的<br>③一阵风吹过，纸锚从她手里飘起来，像风筝一样越飞越高 |
| 6 | 于是，先一个人出发。 | 她看着纸锚飞走，笑了一下，拿起船桨，自己划向远处，海面上留下一道长长的水痕 |

## 二、不敢抵达的地方（约 55 秒）
| # | 字幕 | 画面 |
|---|---|---|
| 7 | 可即使习惯了一个人走，↵也不是哪里都敢去。 | 白天，一条街上的旅行社橱窗贴满海报：雪山、沙漠、古城、雨林。她背着背包一张张看过去，在每一张前都轻松地点点头，走到最后一张前，停住了 |
| 8 | 有些地方，↵到现在仍不敢一个人抵达。 | 最后一张海报：蓝白色的海岛。她伸手想去碰，手停在玻璃前，又收回来 |
| 9 | 比如一座蓝白色的海岛， / 比如一片海上的小木屋。 | 镜头穿过玻璃，进入海报：<br>①蓝白色的海岛：白房子、蓝圆顶，一层层台阶通向海<br>②另一处：碧绿的浅海上，一排木栈道连着一间间水上小木屋 |
| 10 | 总觉得那些地方↵太适合两个人了。 | 海岛上的一切都是成双的：露台上两把椅子、桌上两只杯子、台阶上牵着手的人影、木栈道尽头一架双人秋千 |
| 11 | 海太蓝， / 落日太盛大， / 夜晚又太安静。 | 三个镜头：<br>①蓝得发亮的浅海，一圈圈光斑<br>②巨大的落日几乎铺满整个画面，把白房子染成金色<br>③夜里，海面一点声音也没有，只有满天星星，和水上小木屋里的一盏灯 |
| 12 | 一个人站在那里， / 那些本该叫人幸福的风景， / 大概会让成千上万种孤独↵一起压下来。 | 她一个人站在露台上，身边是两把椅子。落日越来越大，天空越来越高，她显得越来越小。第三屏：天上落下成千上万个灰色的小光点，像下雪一样，一层层压下来 |
| 13 | 并没有强大到↵可以独自承受所有风景。 | 她往后退了一步。镜头一下子退出海报，回到街上的橱窗前：她站在玻璃外，海报上的落日安安静静 |

## 整章逻辑
一直想起“此心安处是吾乡”，可从来没有锚点 → 分不清是没找到地方，还是自己本来就难被锚住 → 于是先一个人出发 → 习惯了一个人走，却仍有不敢一个人抵达的地方 → 那些地方太适合两个人，风景太盛大，一个人承受不住 → 想把它们留给某一个真正愿意一起看的人（下一章：一个人出发以后，也并不总是一个人）
