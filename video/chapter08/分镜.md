# 此心安处 · 终章 此心安处 — 分镜第四稿

- 画幅：9:16 竖屏，约 160 秒
- 第四稿：只留一条主线——**从高原走到海洋，人是怎么一点点变得宽容、平静的**。每一篇都是同一个结构：这个地方是什么样子 → 它教会了什么 → 她因此变成了什么样
  - 高原：建立秩序（理想）
  - 平原：学会团结（扎根）
  - 海洋：学会流动和包容（冒险）
- 和这条主线无关的内容拿掉了：
  - 第八章“真正在找的人”“不勉强同行”两段，讲的是第七章那个人之后的领悟，建议**挪到第七章结尾**，不放在终章
  - “照片留不住”的开头压缩成两屏，只当作她拿起笔的原因
- 字幕来源：**（原文）** 第八章原句；**（你的话）** 你给的句子；**（新写）** 按你的意思写的草稿，请按你的语气改
- 换装：高原篇雪原装，平原篇民族服饰，海洋篇海岛装；草帽和脸始终不变，在连续的场景切换里直接换上
- 插画原则：每个画面一个主体，多留白；画面里不写字
- 音乐：台灯下很淡的钢琴 → 高原：风声和低沉的长音 → 平原：木吉他，像走路的节奏 → 海洋：弦乐和潮水，越来越开阔 → 翻书揭晓时，八音盒完整奏一遍全系列主旋律
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 整章逻辑
照片越拍越多，心情却想不起来，只有创造能留住，于是把这一路从高原画到海洋 → 高原：最开始出发是想用更大的世界稀释痛苦；空气稀薄、视野有限，理想圣洁崇高，给自己建立起了秩序 → 平原：大河边的人围着土地一起生活，他们的归属是一座城、一个家；平原教会了团结 → 海洋：稀少的物资和无边的远方，让人学会出海、驶向未知；归属感对她来说是一种流动的、短暂的状态，答案在每个瞬间；知道前面有危险和分离，更怕不再想出发，所以用热情永不回头 → 从高原走到海洋，慢慢变得宽容、平静 → 继续走，继续一个人看这个世界 → 原来这本书就是她自己画的。此心安处
