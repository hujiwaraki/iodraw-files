# 此心安处 · 终章 此心安处 — 分镜第五稿

- 画幅：9:16 竖屏，约 160 秒
- 第五稿在第四稿的基础上：
  - 去掉“高原教会的是秩序”“平原教会的是团结”这种讲道理的句子，改成从她自己的心情出发：为什么去、看见了什么、自己变成了什么样
  - 加一条贯穿三篇的小线索：**石头**。高原上，她把有棱有角的石头一块块垒成规矩的石堆；平原上，是村里人一起铺在河里的踏脚石，一个人踩过去，后面的人接着踩；海边，是被浪磨圆了的鹅卵石，在浪里滚来滚去，什么形状都装得下。最后她把一颗圆圆的鹅卵石带回来，压在画好的书上
  - 开头压成一句：照片留不住心情，只好画下来
- 字幕来源：**（原文）** 第八章原句；**（你的话）** 你给的句子；**（新写）** 按你的意思写的草稿，请按你的语气改
- 换装：高原篇雪原装，平原篇民族服饰，海洋篇海岛装；草帽和脸始终不变，在连续的场景切换里直接换上
- 插画原则：每个画面一个主体，多留白；画面里不写字
- 音乐：台灯下很淡的钢琴 → 高原：风声和低沉的长音 → 平原：木吉他，像走路的节奏 → 海洋：弦乐和潮水，越来越开阔 → 翻书揭晓时，八音盒完整奏一遍全系列主旋律
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 整章逻辑
照片留不住心情，只好把这一路画下来 → 高原：最开始出发，是想用更大的世界稀释痛苦；那里空气稀薄，只剩干净崇高的理想，于是给自己定了很多规矩，像把有棱角的石头一块块垒起来 → 平原：大河边的人守着同一片土地一起生活，他们的归属是一座城、一个家；原来人和人是可以靠在一起活下去的，就像踩着别人铺好的石头过河 → 海洋：岛上的东西不够，海却无边，人一代代出海；她的归属感也是流动的、短暂的，答案在每个瞬间；比起危险和分离，更怕不再想出发，所以用热情永不回头 → 从高原走到海洋，规矩一条条松开，人像被浪磨圆的石头，慢慢变得宽容、平静 → 继续走，继续一个人看这个世界 → 原来这本书是她自己画的。此心安处
