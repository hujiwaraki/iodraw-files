# 此心安处 · 终章 此心安处 — 分镜第三稿

- 画幅：9:16 竖屏，约 185 秒
- 第三稿：
  - 不再用“吾乡”这个说法：原文“也许‘吾乡’本来就不是一个固定的坐标”改成“也许心安的地方，本来就不是一个固定的坐标”；结尾不再说“是吾乡”
  - 中间“画下来”的部分分成**高原篇、平原篇、海洋篇**：高原教会的是理想和秩序，平原教会的是团结和日常，海洋教会的是冒险、流动和包容。从高原走到海洋，才慢慢变得宽容、平静
  - 加进三句新的话：“用更大的世界稀释痛苦。”“答案在每个瞬间。”“不用浪费时间在某个情绪，用热情永不回头。”
  - 换装：高原篇穿雪原装，平原篇穿民族服饰，海洋篇穿海岛装；草帽和脸始终不变，在连续的场景切换里直接换上
- **字幕来源**：标 **（原文）** 的是第八章原文（只把“吾乡”换掉）；标 **（你的话）** 的是你刚给的三句；标 **（新写）** 的是我按你的意思写的草稿，请按你的语气改
- 整章结构：她回到房间翻照片，想不起当时的心情 → 拿起笔开始画 → 镜头钻进纸里，画会动：高原篇 → 平原篇 → 海洋篇 → 镜头拉远，她画的正是每一章开头翻开的那本墨绿色的书
- 插画原则：每个画面一个主体，多留白；画面里不写字；不用前几章的铁盒、车票、手账、明信片架、橱窗倒影、蒲公英和种子、光点、粉笔圆、雾、气球、月台、纸飞机
- 音乐：开头台灯下只有很淡的钢琴 → 高原篇：风声、低沉的长音、像心跳的鼓 → 平原篇：木吉他，像走路一样的节奏 → 海洋篇：弦乐和潮水，越来越开阔 → 翻书揭晓时，八音盒完整奏一遍全系列的主旋律
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 整章逻辑
照片太多，反而想不起当时的心情；照片留得住风景，留不住那时候的自己 → 只有创造能留住它们，于是拿起笔；当初出发，只是想用更大的世界稀释痛苦 → 高原：空气稀薄，理想圣洁崇高，学会了秩序；也明白了真正在找的人是什么样子，在那之前不停止生活，也不勉强同行 → 平原：大河边的人围着土地一起生活，学会了团结和日常；心安的地方不是固定的坐标，是一个个短暂的瞬间，答案就在每个瞬间 → 海洋：稀少的物资和无边的远方，学会了冒险、流动和包容；知道前面有危险和分离，更怕不再想出发，所以不浪费时间在某个情绪，用热情永不回头 → 从高原走到海洋，才慢慢变得宽容、平静 → 所以继续走，继续一个人看这个世界 → 原来每一章翻开的那本书，就是她自己画的。此心安处
