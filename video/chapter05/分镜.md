# 此心安处 · 第五章 同路人 — 分镜第一稿

- 画幅：9:16 竖屏，约 165 秒
- 两条贯穿全章的线：
  - **蒲公英种子**（接第四章结尾）：几颗种子在风里一起飞了一段，又被风吹散，各自飘向不同的方向
  - **小小的光**：深夜屋顶上，大家说起心里话的时候，话变成一只只萤火一样的小光点飞出来；章尾她一个人在房间里关了灯，这些光点又回来了，陪着她
- 插画原则：每个画面一个主体，多留白；画面里不写字；用光、影子、空镜说话
- 与前几章不雷同：不用铁盒、车票、手账、明信片架、橱窗倒影；不再出现第四章的长桌举杯、浅海慢走
- 系列暗线：路人一直是灰色、没有脸的剪影。同路人在一起时是彩色的，分开以后，在人群里又慢慢变回灰色剪影
- 色调：清晨 → 热闹的暖色（傍晚、夜里的小灯）→ 分别时的灰 → 空镜的余晖 → 深夜房间的暗蓝里亮起暖光
- 音乐：吉他和轻快的手鼓，热闹段加口琴般的簧片；分离后只剩吉他；章尾八音盒
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 整章逻辑
一个人出发，却并不总是一个人 → 很多短暂的同路人：一起骑车、喝酒、桌游、爬高原、追落日 → 很快熟悉，说起不会告诉别人的事 → 可只认识了几天，旅程结束各自散开，永远分离 → 慢慢不再对相遇抱太多期待，学会轻盈地飞走；离开不难，留下才难 → 有些人只属于那几天、那些地方，离开就变回陌生人 → 可那些相遇没有失去意义，那些愉快的夜晚后来陪伴了很多孤寂的夜晚 → 人不在了，时刻还在
