# 此心安处 · 第六章 模糊地带 — 分镜第一稿

- 画幅：9:16 竖屏，约 140 秒
- 字幕：原文从“也是在一次次相遇和分离里，慢慢学会了接受模糊地带”到“又觉得活着似乎也没那么糟”，一字不改，只按每屏规则拆开
- 两条线：
  - **雾**：开头她走进一片雾里，远处的东西都看不清边界——这就是“模糊地带”
  - **没画完的圆**：她用粉笔画一个圆，怎么也接不上；后来这个缺了一口的圆升上夜空，变成一弯月亮。缺口不是没完成，月亮本来就是这样的。章尾回家的路上，那弯月亮又挂在天上
- 插画原则：每个画面一个主体，多留白；画面里不写字；用光、影子、天气说话
- 与前几章不雷同：不用铁盒、车票、手账、橱窗倒影、蒲公英、萤火光点
- 色调：雾的灰白 → 夜里的深蓝和月光 → 雨天的灰 → 最后忽然一朵很好看的云，暖起来
- 音乐：钢琴 + 大提琴，大量留白；“很烂”那段只剩雨声；看到云的时候，钢琴旋律第一次完整地出现；结尾吉他加进来，轻轻的
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 整章逻辑
一次次相遇和分离里，学会接受模糊地带 → 关系、故事、告别，不一定有定义、结尾和解释；发生了就是发生了，来过就是来过了 → 以前觉得没有结果就是没完成，后来明白人生本来就不会闭环 → 遗憾、奇怪的关系、说不清的话，就让它们悬在那里，继续生活 → 人间不完美，甚至很烂 → 可还是得吃饭睡觉工作赶车，还是会看到好看的云，还是会因为一顿饭、一阵风、一次谈话，觉得活着也没那么糟
