# 此心安处 · 第六章 模糊地带 — 分镜第六稿

- 画幅：9:16 竖屏，约 136 秒
- 这一稿调整了顺序，让情绪走成一条线：**很烂的时候 → 在相遇和分离里学会接受模糊 → 不会闭环的就让它悬着 → 继续生活 → 还是会看到好看的云**
  - 原文“人间很烂”那一段放到最前面：先难过，才有后面的“接受”
  - 原文“可还是得吃饭，睡觉，工作，赶车”跟在“然后继续生活”后面，去掉开头的“可”字，变成“还是得吃饭，睡觉，工作，赶车”，和后面两句“还是会……”连成一串
  - 第六稿：新加一句“很多答案，都是在人生的路上走了很久很久，才自然而然明白的。”放在全章最后，作为收尾：前面那些想通的事，都不是在旅行里找来的，是走了很久之后自己明白的
  - 其他字幕一字不改
- 画面也连成一条线：天气一路变过去——**大雨 → 雨停了起雾 → 雾散了是夜晚，月亮出来 → 第二天的日常 → 傍晚好看的云 → 回家路上又是那弯月亮**
- 贯穿的小线索：**没画完的圆**。她用粉笔画一个圆，怎么也接不上；后来这个缺了一口的圆升上夜空，变成一弯月亮。章尾回家的路上，那弯月亮还挂在天上
- 插画原则：每个画面一个主体，多留白；画面里不写字；不用前几章的铁盒、车票、手账、橱窗倒影、蒲公英、萤火光点
- 音乐：开头只有雨声和低低的大提琴 → 起雾后钢琴一个音一个音地进来 → 报复性找答案时又急又快，睡着时戛然而止 → 月亮升起时第一次有了旋律 → 日常的快切加轻快的节拍 → 看到云时旋律完整地出现，吉他加进来 → 最后一句旋律放慢，只剩钢琴，落在一个长长的和弦上
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 整章逻辑
人间不完美，甚至很烂：失望、失去、被辜负、开心时想到离别、孤独时没人说话 → 也正是在一次次相遇和分离里，学会了接受模糊地带：关系不一定有定义，故事不一定有结尾，告别不一定有解释；发生了就是发生了，来过就是来过了 → 以前觉得没有结果就是没完成，有时候在旅行里报复性地找答案，后来明白人生本来就不会闭环 → 遗憾、奇怪的关系、说不清的话，就让它们悬在那里，继续生活 → 还是得吃饭睡觉工作赶车，还是会看到好看的云，还是会因为一顿饭、一阵风、一次谈话，觉得活着也没那么糟 → 而这些答案，都不是找来的，是在人生的路上走了很久很久，才自然而然明白的
