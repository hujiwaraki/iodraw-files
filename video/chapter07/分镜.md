# 此心安处 · 第七章 那个人 — 分镜第六稿

- 画幅：9:16 竖屏，约 195 秒
- 第二稿：在“知道了彼此并不是一路人”和“四个月后”之间，新加一段内心的动摇（“当然，也有过动摇的时候……是自己太理想主义了”）。那四个月，正好是她动摇的四个月
- 第六稿：去掉了纸杯和线。贯穿全章的改成纸飞机：隔着一片屋顶的两扇窗，纸飞机飞来飞去；后来再没有纸飞机飞来，远处那扇窗灭了；最后一只纸飞机打开是一张空白的纸，被风吹走
- 第五稿：字幕和画面描述里的“他”都改成“ta”（“他们”改成“ta们”）
- 第四稿：第 8、15、16 句按你的意思改了字幕；第 15 句换成两盏路灯的光圈，第 16 句重新分镜，集中在一个房间、一段回忆里
- 第三稿：在“暂时从原来的生活里脱离了出来”后面，新加高原上听见自己心跳的一句
- 原文范围：从“后来有一次，把下一段旅行的计划告诉了……”到“但这并不意味着ta们要留下来。”字幕全部是原句，只按规则拆屏
- **“ta”的画法**：只用浅灰的虚线勾出轮廓，没有脸、没有颜色，从头到尾都画不实——ta来过，但始终没有真正走进她的画面里
- **贯穿全章的线索：纸飞机**。她和 ta 的窗隔着一片夜里的屋顶，计划、机票，都是一只只飞过屋顶的纸飞机；后来再没有纸飞机飞来，远处那扇窗灭了；最后飞来的一只，打开是一张空白的纸，被风吹走
- 插画原则：每个画面一个主体，多留白；画面里不写字；用光、影子、天气说话；不用前几章的铁盒、车票、手账、明信片架、橱窗倒影、蒲公英、光点、粉笔圆、雾、气球、月台
- 色调：夜里温暖的窗光 → 旅途的明亮 → 博物馆里两团不一样的光 → 克制的灰白 → 冬天 → 春天的清晨
- 音乐：极简钢琴，大量留白。纸飞机飞起来时有一声轻轻的拨弦；高原那一句只剩心跳和风声；动摇那一段，两只节拍器的嘀嗒声快慢不一、时对时错；远处那扇窗灭掉的那一下，所有声音都停住
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 整章逻辑
把计划告诉了一个旅途中认识的人，ta订了票，她也订了，以为短暂的旅伴这次能走远一点 → 一起上路才发现，陪伴不等于同行：她在博物馆看入神，ta在申请下一段签证 → 因为对她来说，旅行是长久地看、慢慢理解、在天地间安静下来；甚至在高原上听见自己的心跳，才觉得用力地活着——那是一场很私人的对话 → 有些陪伴让人离世界更近，有些更远；知道了彼此的交集其实很小 → 也动摇过：分不清是自己太独来独往、对人忍耐度太低，还是这个世界的问题；ta很好，可就是不合拍，也许是自己太理想主义 → 四个月后ta删了联系方式，只留下“万事向前看”，孤寂还是涌上来：原来孤独也可以是有人来过又离开 → 经历了太多相遇和分离，最后还是接受了：有人会陪一段，但并不意味着要留下来
