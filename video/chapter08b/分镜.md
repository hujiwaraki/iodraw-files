# 此心安处 · 第八章 她的小时候 — 分镜第二稿

- 画幅：9:16 竖屏，约 115 秒；放在第七章《那个人》之后、终章之前
- 第二稿：整章换一根主线。**一个喜新厌旧、去过的地方很少再去第二次的人，为什么同一座城去了三次？** 开头提出这个问题，中间是第一次去的经过（她的小时候、外婆、吃、夜里聊天），后面“第二次、第三次”用同一个梯坎、同一个机位拍三遍，最后给出答案：让我回来的不是风景，是人
- 外婆的事不编具体故事：用“那些故事我没有亲眼见过，见到外婆就懂了”带过去
- 不写真实地名，用画面表现山城：楼顺着山坡一层叠一层、长长的梯坎、从楼中间穿过去的轻轨、江边的台阶；不用雾
- 好朋友：青绿色外套、马尾；外婆：白头发、碎花围裙
- 字幕来源：**（你的话）** 你给的句子；**（新写）** 按你的意思写的
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 配乐
开头一段往前赶的拨弦（一路向前、不回头）→ 停在山城时停一拍 → 小时候：八音盒 → 外婆和一桌菜：热闹一点，手鼓 → 夜里聊天：只剩很轻的钢琴，灯一盏盏灭时几个轻轻的高音 → 心和心的距离：一个长长的和弦 → 第二次、第三次：同一句旋律弹三遍，一遍比一遍完整 → 答案：旋律慢慢收回系列的主题

## 整章逻辑
我是个喜新厌旧的人，去过的地方很少再去第二次 → 可这座山城已经来了第三次 → 第一次是她带我来的，一路听她讲小时候，讲得最多的是很善良的外婆 → 那些故事没见过，见到外婆就懂了 → 一大桌菜、一路的小吃 → 晚上挤在一张床上聊到很晚，原来心和心的距离可以这么近 → 后来又来了第二次、第三次，路还是那条路，外婆还是那样拉住我的手；两个人在一起很轻松 → 一次次回来，不是为了风景，是为了人 → 那是她的家乡，可那座山城里，也有一盏灯为我亮着
