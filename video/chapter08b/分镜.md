# 此心安处 · 第八章 同路人 — 分镜第十一稿

- 画幅：9:16 竖屏，约 97 秒；放在第七章《那个人》之后、终章之前
- 第八稿：只讲三次来这座城、她陪着一起回去、吃的、夜里聊到凌晨；字幕和画面里都不出现外婆，也不用第一人称
- 第九稿：章节名改为《同路人》
- 第十一稿：第 6 句改成“沉甸甸的过去”和“如今巴适的生活”，慢慢更懂她了；第 8 句好朋友不笑，把甜点推过去
- 第十稿：第 5 句后面加一句老城的一砖一瓦、这座城沉甸甸的过去，慢慢明白她为什么是现在的她
- 不写真实地名，用画面表现山城：楼顺着山坡一层叠一层、长长的梯坎、从楼中间穿过去的轻轨；不用雾
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 配乐
比前几章更暖、更轻快：开头往前赶的拨弦 → 前两次的火锅：单薄一点 → 跟她一起去：拨弦和轻轻的手鼓 → 小时候：八音盒 → 老城和防空洞里的火锅：先是低低的大提琴，进洞后热闹的拨弦一点点回来 → 小摊：热闹一点 → 夜里聊天：只剩很轻的钢琴 → 心和心的距离：一个长长的和弦 → 长椅上睡着：慢下来 → 离开：旋律慢慢收回系列的主题

## 整章逻辑
一向喜新厌旧，去过的地方基本不会再去 → 这座城却去了三次 → 前两次只吃了两顿火锅 → 这次是跟她一起去的：你想去，我可以和你一起回去 → 一路听她讲小时候 → 走过老城的一砖一瓦，这座城有过沉甸甸的过去，如今的日子却过得很巴适，跟着她走这一趟，好像也慢慢更懂她了 → 吃了好多她从小吃到大的东西 → 晚上挤在一张床上，到了凌晨她还在说哪家好吃、哪里好玩 → 心和心的距离可以这么近 → 两个人待在一起很舒服 → 说不清为什么，好像变得包容了许多；可和她在一起，其实也没什么需要包容的；人和人之间的和谐，或许就在于匹配
