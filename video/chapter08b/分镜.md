# 此心安处 · 第八章 她的小时候 — 分镜第六稿

- 画幅：9:16 竖屏，约 85 秒；放在第七章《那个人》之后、终章之前
- 第六稿：去掉“我”的第一人称叙述，字幕里的“她”只指好朋友。第五稿：再口语一点，像跟朋友聊天那样说；辣的那句改成“挺能吃辣，就是肠子不太服气”。第四稿：去掉“AI 味”。不对仗、不升华、不替你编感受，像平时说话一样平平地讲：我喜新厌旧，这座城却来了三次；第一次其实只吃了两顿火锅；这一次是她带我来的；外婆、吃的、夜里聊天；最后只说一句“因为她，破了一次例”
- 第六稿：去掉“我”的第一人称叙述，字幕里的“她”只指好朋友。第五稿：外婆已经是回忆了。她不出现在“现在”的画面里，只出现在暖色、柔光的回忆里；不再有见外婆、外婆做菜、外婆送别的画面
- 外婆的事不编具体故事，只说“很善良”
- 不写真实地名，用画面表现山城：楼顺着山坡一层叠一层、长长的梯坎、从楼中间穿过去的轻轨、江边的台阶；不用雾
- 好朋友：青绿色外套、马尾；外婆：白头发、碎花围裙
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 配乐
比前几章更暖、更轻快：开头往前赶的拨弦 → 第一次的火锅：单薄一点 → 她带我来：拨弦和轻轻的手鼓 → 小时候：八音盒 → 小摊：热闹一点 → 夜里聊天：只剩很轻的钢琴 → 心和心的距离：一个长长的和弦 → 江边：慢下来 → 离开：旋律慢慢收回系列的主题

## 整章逻辑
我喜新厌旧，去过的地方一般不会再去 → 这座城是例外，来了三次 → 第一次其实只吃了两顿火锅 → 这一次是她带我来的，看她长大的地方 → 她一路讲小时候，讲得最多的是外婆，很善良，外婆已经是回忆了 → 她从小吃到大的那几家 → 晚上挤在一张床上聊到很晚，心和心的距离可以这么近 → 和她在一起很轻松 → 我还是喜新厌旧，只是因为她，破了一次例
