# 此心安处 · 第八章 她的小时候 — 分镜第三稿

- 画幅：9:16 竖屏，约 105 秒；放在第七章《那个人》之后、终章之前
- 第三稿：前两次是自己来的，第三次才是她带我来的。主线改成：**一个喜新厌旧的人，本来不会再来第三次，是因为她，才打破了喜新厌旧**。同一座城，跟着她走，像换了一座城
- 前两次和第三次用同一个梯坎、同一个机位：前两次她一个人、偏灰、拍张照就走；第三次好朋友在台阶上回头等她，颜色暖起来
- 外婆的事不编具体故事：用“那些故事我没有亲眼见过，见到外婆就懂了”带过去
- 不写真实地名，用画面表现山城：楼顺着山坡一层叠一层、长长的梯坎、从楼中间穿过去的轻轨、江边的台阶；不用雾
- 好朋友：青绿色外套、马尾；外婆：白头发、碎花围裙
- 字幕来源：**（你的话）** 你给的句子；**（新写）** 按你的意思写的
- 字幕规则：每屏最多两行、每行不超过 15 字；“/”换屏，“↵”屏内换行

## 配乐
开头一段往前赶的拨弦（一路向前、不回头）→ 前两次来山城：同一句旋律，单薄、偏冷 → 第三次她回头等我：同一句旋律加上暖暖的和声 → 小时候：八音盒 → 外婆和一桌菜：热闹一点，手鼓 → 夜里聊天：只剩很轻的钢琴，灯一盏盏灭时几个轻轻的高音 → 心和心的距离：一个长长的和弦 → 江边：慢下来 → 答案：旋律慢慢收回系列的主题

## 整章逻辑
我是个喜新厌旧的人，去过的地方很少再去第二次 → 这座山城已经来过两次，本以为不会再来 → 第三次，是她说带你去看看我长大的地方 → 同一座城跟着她走像换了一座，每个路口都有她的小时候，讲得最多的是很善良的外婆 → 那些故事没见过，见到外婆就懂了 → 一大桌菜、她从小吃到大的小摊 → 晚上挤在一张床上聊到很晚，原来心和心的距离可以这么近 → 两个人在一起很轻松 → 让我打破喜新厌旧的，不是这座城，是她 → 那是她的家乡，可那座山城里，也有一盏灯为我亮着
