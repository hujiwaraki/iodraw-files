# 此心安处 · 第二章 一个人 — 分镜第十稿

- 画幅：9:16 竖屏（1080×1920），30fps，约 180 秒
- 人物：黄外套、草帽、行李箱，不背包；戴帽子时为 A 侧分短发，不戴帽子时齐平微翘短发
- 色调：灰蓝的城市 → 高原很蓝的天空，但她周围是冷的 → 团餐的手机蓝光 → 灰色的等待 → 结尾地图上暖光一个个亮起
- 音乐：一把吉他独奏；高原段加入风声与稀薄的呼吸；团餐段几乎无声，只有碗筷和转盘；结尾节奏轻快
- 暗线：别人的“视线”画成一圈圈小线条落在她身上（第三章用同样构图让视线消失）
- 不展示具体地点：高原、地图上都不写地名
- 字幕规则：每屏最多两行、每行不超过 15 个字、每屏至少停留 2.5 秒；超长的句子拆成两屏（表中用 / 表示换屏，↵ 表示屏内换行）

## 整章逻辑
现在打开铁盒，想起第一次 → 只想逃，没人陪，只好跟团 → 在团里看清：两个人也可能很寂寞 → 回家，把第一张车票放进铁盒 → 也想等一个真正合适的人，可等不来 → 怕孤独也怕衰老，衰老压过了一切 → 于是不再等，一个人出发 → 真的上路才知道不浪漫、有危险、怕被看 → 可慢慢也习惯了 → 回到现在：满桌车票，不知不觉去了很多地方
